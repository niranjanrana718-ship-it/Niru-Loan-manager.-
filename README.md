# Niru Loan Manager — Android starter
This is a starter Android project for the loan-management app.
Production requirements:
- Secure backend/database and role-based authentication.
- Explicit, auditable borrower consent and data minimization.
- Compliant payment-gateway merchant account and server-side payment verification.
- Loan agreement, APR/charges disclosures, receipts and audit logs.
- Legal/regulatory review before offering loans to the public.
The included PAY EMI button is DEMO ONLY and cannot move real money.
